# 1.2.3 蜂窝网络诊断

## 现象

- Wi-Fi 下网易云解析和音频播放正常。
- 切换手表 LTE 后，歌曲长时间停留在连接状态，最终没有开始播放。

## 真机结果

- 设备：OPPO OWW221 / API 30 / ADB `2e28bb17`。
- 当前默认网络：LTE，APN `3gnet`，IPv4 `10.213.85.139/29`，同时取得 IPv6 地址。
- 移动数据和漫游开关均开启，应用 UID `10128` 的网络策略为 `rules=0 (NONE)`。
- `INTERNET`、`ACCESS_NETWORK_STATE` 权限已授予。
- 应用解析播放地址时，到 `music.163.com:443` 在 12 秒连接阶段超时。
- 从手表系统直接访问 `music.163.com`、`interface.music.163.com`、`p1.music.126.net` 均连接超时。
- 从手表系统直接访问百度、QQ 和 OPPO 域名也连接超时，IPv4 与 IPv6 结果相同。

## 结论

失败发生在系统蜂窝数据出口，早于网易云鉴权、音质选择和音频下载。它不是单曲、码率、缓存、应用联网权限或“仅 Wi-Fi”设置造成的。

系统显示 `VALIDATED` 不代表已实际访问公网。固件日志显示 NetworkMonitor 对 BT/eSIM 网络直接返回成功，没有进行真实联网探测。

优先检查 eSIM/实体 SIM 的数据套餐和运营商侧开通状态，其次重建移动数据连接并核对联通 APN。应用侧后续应增加真实公网探测和快速错误提示，避免每个音质档连续等待 12 秒。
