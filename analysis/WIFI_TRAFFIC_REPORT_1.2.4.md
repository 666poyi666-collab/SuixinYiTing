# 1.2.4 Wi-Fi 音乐流量报告

## 测试环境

- 设备：OPPO OWW221 / Android API 30。
- Wi-Fi：RSSI 约 -48 dBm，物理链路速率 72 Mbps。
- 歌曲：《断桥残雪》，服务端实际返回无损 FLAC。
- 服务端码率：1,598,781 bps。
- 音频正文：45,397,550 bytes，即 45.40 MB / 43.29 MiB。
- 歌曲时长：约 227.16 秒。

## 实测速度

- Range 分块：174 个，单块 256KB，最后一块 46,638 bytes。
- 纯传输累计耗时：37.21 秒。
- 突发平均下载速度：9.76 Mbps。
- 单块速度：主要为 9-25 Mbps，首轮最低约 1.38 Mbps，最高约 31.30 Mbps。
- 持续播放所需平均速度：约 1.60 Mbps。

播放器会利用 Wi-Fi 提前下载，因此网络表现为若干高速突发，而不是始终保持 1.60 Mbps。缓存能够覆盖短时速度下降。

## 每首歌流量

本次音频正文为 45.40 MB。加上播放地址、歌词、封面、HTTPS 和 TCP/IP 开销，流量预算按约 46-48 MB 较稳妥。

| 实际档位 | 常见码率 | 每分钟音频正文 | 4 分钟歌曲 |
| --- | ---: | ---: | ---: |
| 标准 | 128 kbps | 0.96 MB | 3.84 MB |
| 较高 | 192 kbps | 1.44 MB | 5.76 MB |
| 极高 | 320 kbps | 2.40 MB | 9.60 MB |
| 无损 | 700-1600 kbps | 5.25-12.00 MB | 21-48 MB |
| Hi-Res | 2000-6000 kbps | 15-45 MB | 60-180 MB |

实际消耗以界面显示的“实际音质”和缓存层记录的 `audioBytes` 为准。服务端降档时按实际档位计费，不按请求档位计费。

## 月度估算

以本次 45.40 MB 无损歌曲为例：

- 每天 10 首：约 454 MB，30 天约 13.6 GB。
- 每天 20 首：约 908 MB，30 天约 27.2 GB。
- 1000 首全部各播放一次：音频正文约 45.4 GB；不同歌曲码率和时长会改变结果。
