## Bug 处理规则

1. 新 Bug 先分配稳定 `BUG-nnn`，不得只写在聊天或临时 TODO。
2. 记录复现版本、环境、最小步骤、预期、实际和证据。
3. 根因未证实时写“调查中”，不把猜测写成结论。
4. 修复必须链接版本文档和回归 Test ID。
5. 复发时沿用原 Bug ID，增加复发版本与新根因，不创建重复条目。
6. 环境问题也保留记录，说明怎样重新验证。
