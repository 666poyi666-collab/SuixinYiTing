# 随心一听项目长期维护手册

## 1. 项目目标

“随心一听”是在现有手表音乐播放器母版上持续迭代的产品，不是另起炉灶重写 UI。项目保留母版本地音乐能力和交互结构，通过独立 `network-bridge` 接入网易云账号资料库与实时音频，重点解决千首歌单加载、随机播放、播放信息融合、歌词和音质可见性。

产品原则：

1. 母版已有且有效的功能优先复用，网络音乐必须融入同一套菜单和播放页。
2. 修复新问题时必须回归已完成能力，禁止用一个回归换取一个修复。
3. 用户看到的是系统实际状态：实际歌曲、实际进度、实际音质、实际耳机 Codec 和实际系统音量。
4. 账号资料库只同步元数据，音频按需流式播放；清除临时缓存不等于退出登录或删除资料库。
5. 每个版本有独立 APK、修复文档、验证记录与 SHA-256，可安装、可核验、可回滚。

## 3. 项目边界

### 3.1 本项目负责

- 网易云登录、歌单/歌曲/专辑/歌手元数据、歌词、封面和播放地址解析。
- 资料库缓存、完整列表、分类、随机袋、历史和网络播放队列。
- 网络播放器、Range 缓存、音质选择、系统音量映射和 MediaSession。
- 将网络状态映射到母版菜单、播放页、歌词页、进度条、封面背景和控制按钮。
- 构建补丁、APK 注入、签名、真机安装、回归、日志和版本制品。

### 3.2 外部边界

- 网易云服务端决定账号权益、歌曲版权、可用音质和短期播放地址。
- Android/OPPO 固件决定蓝牙 Codec、系统预装权限、后台策略和硬件解码能力。
- 普通 APK 不包含固件缺失的 LHDC 编码器；当前 OWW221 与 Enco Free4 的共同最高档为 AAC。
- 写入 `/system` 或 `/product` 依赖工程固件、root 或厂商签名；当前通过 MediaSession 和 AudioService 完成系统媒体识别。
- 公开仓库提供桥接源码和补丁脚本，不提交本地签名密钥、登录会话、反编译缓存或第三方 APK。

## 4. 强制开发流程

每个功能批次按以下顺序执行：

1. 在 `REQUIREMENTS.md` 新增或更新需求 ID、状态和验收条件。
2. 确定新版本号，先创建 `docs/bugfixes/<version>.md`。
3. 在 `DEVELOPMENT_LOG.md` 写“开始版本”，记录目标和基线。
4. 备份并保留上一版 APK，禁止覆盖旧制品。
5. 只修改完成需求所需的代码、补丁和资源。
6. 编译 bridge，重建、注入、zipalign、签名并执行签名校验。
7. 使用明确的 ADB 序列号覆盖安装；多设备在线时禁止省略 `-s`。
8. 执行 `QA_REGRESSION.md` 的必测项和本版本专项测试。
9. 用日志、UI 层级、截图、MediaSession 或哈希记录可复核证据。
10. 更新需求状态、Bug 总表、版本文档、开发日志和发布信息。

## 5. Definition of Done

一个需求只有同时满足以下条件才标记为“完成”：

- 实现已进入版本化源码，不是仅靠 ADB 临时设置或人工操作。
- 构建成功，APK 签名验证通过，版本号高于上一制品。
- 在目标手表完成用户可见路径验证。
- 相关旧功能完成回归，没有未记录的退化。
- 验收证据进入版本文档或开发日志。
- 需求基线和 Bug 总表状态已更新。
- APK、SHA-256 和回滚版本可定位。

“代码已写”“编译通过”“日志看起来正常”单独都不等于完成。

## 6. 防回归规则

- 菜单跳转按稳定语义/ID 映射，不按 `ConcatAdapter` 后的绝对位置猜测。
- 网络播放页每次进入都主动请求服务当前状态，不能依赖错过即丢失的单次广播。
- 播放状态的标题、歌手、封面、歌词、进度、音质和 Codec 必须来自同一当前曲目状态。
- 系统媒体音量是唯一可见音量控制；内部增益只实现固定曲线，不再提供第二个“应用音量”数值。
- 清除缓存只删除临时音频/图片；账号会话和资料库元数据需要独立的退出登录/重置动作。
- 任何 UI 修改必须检查 378x496 截图，文字不得重叠、裁切或遮挡交互控件。
- 任何播放修改必须回归封面、完整歌词、seek、音量、MediaSession、后台恢复和随机队列。

## 7. 文档治理

- 文档使用 UTF-8 Markdown，需求与 Bug 使用稳定 ID，不因排序变化重编号。
- 日志只追加实际发生的操作和结果；错误路线保留结论，但明确标记“未采用”或“验证失败”。
- 历史 APK、截图和报告不覆盖；更正结论时新增说明并链接原记录。
- 新文档必须加入 `docs/INDEX.md`，README 只保留项目概览和入口。
- 版本发布前运行链接检查、敏感信息扫描与 `git status` 检查。

## 8. 当前优先级

1. P0：播放、登录、资料库、队列或设置路由导致应用不可用/数据丢失。
2. P1：千首歌单、随机一轮无重复、歌词/封面/进度、音量和音质显示回归。
3. P2：实体耳机按键、本地/网络切换、网络播放 DSP 和背景选项融合。
4. P3：逐字/翻译歌词、更多网络源、系统预装研究和体验优化。
