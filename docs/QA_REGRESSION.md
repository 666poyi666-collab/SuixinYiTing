# 随心一听测试与回归矩阵

## 1. 测试分级

- `Smoke`：每次安装后执行，约 5-10 分钟。
- `Core`：每个修复版本发布前执行。
- `Extended`：播放、资料库、缓存、迁移或系统集成大改时执行。
- `Soak`：正式里程碑版本执行长时间播放、功耗、缓存和断网恢复。

每个结果记录：版本、设备、网络、耳机、步骤、预期、实际、证据路径、结论。
