# 1.2.4 音量与 Wi-Fi 流量测量

## 用户需求

- 测量 Wi-Fi 听歌时的实际下载速度和每首歌流量。
- 修复系统最低非静音档仍然过响、档位变化突兀的问题。
- 保留此前歌词、封面、音质、seek、菜单、登录和媒体会话能力。

## 实现

- 缓存层记录音频文件总字节数、每个 256KB Range 分块、下载耗时、吞吐率及本次累计字节数。
- 系统 `STREAM_MUSIC` 继续作为唯一音量控制和显示来源。
- 网络播放器增加低端输出曲线：最低非静音档约 34%，随系统档位逐步增加，最大档为 100%。
- 音量变化使用约 120ms 渐变，减少系统 16 档造成的突跳。
- 不恢复独立应用音量百分比，不放大音频信号。
