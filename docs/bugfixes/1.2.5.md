# 1.2.5 端到端音质识别

## 用户需求

- 解决播放页只显示网易云源音质、无法判断耳机最终音质的问题。
- 核查并提升 OWW221 连接 OPPO Enco Free4 时的蓝牙输出质量。

## 调查结论

- 当前网易云源可获得无损 FLAC，例如《一笑倾城》为 972 kbps。
- OWW221 与 Enco Free4 实际协商为 AAC、48 kHz、16-bit、立体声、165 kbps CBR。
- OWW221 系统包含 LDAC 编码库，但 Enco Free4 不提供 LDAC；耳机提供 LHDC，而 OWW221 固件没有 LHDC 编码库。
- Android 蓝牙服务已启用可选 Codec，并已选择双方共同支持的最高档 AAC。
- production 固件禁止普通应用修改 A2DP offload 属性，应用层不能补入缺失的系统 LHDC 编码器。

## 实现

- 监听 A2DP Codec 配置变化并保存当前耳机输出规格。
- 播放页改为两行：第一行歌手，第二行同时显示源音质与耳机实际 Codec。
- 继续使用无损源作为 AAC 编码输入，避免有损源再次 AAC 转码。
- 连接其他耳机时自动识别 SBC、AAC、aptX、aptX HD 或 LDAC。

## 验证

- [x] Enco Free4 重连后识别 `AAC 165k · 48k/16bit`。
- [x] 播放页两行文字完整显示且不遮挡标题（最终由 1.2.8 紧凑布局完成）。
- [x] 无损源、封面、歌词、seek、音量和 MediaSession 保持正常。
- [ ] 连接支持 LDAC 的耳机时自动显示 LDAC。
