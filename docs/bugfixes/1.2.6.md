# 1.2.6 播放状态与音质显示恢复

## 用户需求

- 耳机连接后直接显示当前实际音质。
- 已在后台播放时，重新进入播放页仍要显示歌曲、封面、歌词、进度和音质。
- 修复时保留既有功能和历史版本。

## 根因

- 网络播放服务按秒广播状态，但播放页只监听注册之后的新广播。
- Activity 重建或从系统设置返回时，可能错过上一条广播并停留在母版的“未播放”占位状态。

## 修复

- 新增 `REQUEST_STATE` 动作，播放页安装桥接器后主动向现有服务请求一次完整实时状态。
- 服务回传当前歌曲、播放位置、完整歌词、封面、源音质和蓝牙输出 Codec。
- 保留后台每秒更新以及 A2DP Codec 变化广播，兼顾首次进入与实时变化。

## 验证

- [x] 覆盖安装并保留登录、1242 首资料库和设置。
- [x] Enco Free4 显示 `AAC 165k · 48k/16bit`。
- [x] 从系统设置/后台返回后播放页不再显示“未播放”。
- [x] 封面、完整居中歌词、seek、音量曲线和 MediaSession 正常。
- [x] 应用日志没有 `FATAL EXCEPTION`。
