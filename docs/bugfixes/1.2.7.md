# 1.2.7 冷启动耳机音质恢复

## 用户需求

- 耳机已经连接时，应用冷启动也必须显示当前实际蓝牙输出音质。
- 不要求用户为了看到音质而手动断开并重连耳机。

## 根因

- 1.2.5 只消费新的 A2DP Codec 变化事件；覆盖安装或服务重启发生在耳机连接之后时，当前进程没有收到历史事件。
- 1.2.6 修复了播放状态回填，但截图确认源音质恢复后耳机 Codec 仍为空。

## 修复

- 注册 A2DP Codec Receiver 时读取系统返回的当前粘性 Codec 状态。
- 冷启动恢复与实时 Codec 变化复用同一个解析和持久化函数。
- 后续状态回填会携带已恢复的 Codec，无需重新连接耳机。

## 验证

- [x] Enco Free4 重连事件识别并持久化 `AAC 165k · 48k/16bit`。
- [x] Enco Free4 播放页显示 `耳机 AAC 165k · 48k/16bit`。
- [x] 从后台返回后歌曲、封面、源音质与耳机音质均存在。
- [x] 登录资料库仍为 1242 首，随机池仍为 1230 首。
- [x] 无 `FATAL EXCEPTION`。
