## 根因与修复

### BUG-030：系统媒体音量被二次衰减

`NetworkStreamService.applyOutputGain()` 按 `index / max` 对 `MediaPlayer`
再乘一次线性增益。设备的 AudioPolicy 已经对 `STREAM_MUSIC` 应用了自己的曲线，
真机 `dumpsys media.audio_policy` 读到 `DEVICE_CATEGORY_HEADSET` 为
`(1, -58dB) (20, -40dB) (60, -17dB) (100, -2dB)`。两层叠加后，Enco Free4 的
3/16 档由 -41 dB 变成约 -55 dB，低档几乎听不到，且界面档位与实际响度不一致。

修复：播放器恒定 unity 增益，只保留启动/恢复的 120 ms 防爆音渐入；系统媒体流
成为唯一衰减来源。日志改为 `output gain=1.0 (unity) system=n/16`。

### BUG-031：音量键不落到媒体流

Activity 从未调用 `setVolumeControlStream()`，注入 `KEYCODE_VOLUME_UP` 时
`STREAM_MUSIC` 不变。修复：`MainActivity`（经 bridge）与 `NetworkMusicActivity`
均设置 `AudioManager.STREAM_MUSIC`。同时新增 `ACTION_ADJUST_VOLUME` /
`ACTION_SET_VOLUME`，所有应用内音量入口统一写系统媒体流，状态广播携带
`volume` 与 `volumeMax` 供界面镜像。

### BUG-032：每秒时间文本触发全窗口重新布局

播放页新增的已播/总时长使用 `wrap_content`。`TextView.checkForRelayout()`
只有在宽高都不是 `wrap_content` 时才走「仅 invalidate」分支，因此每秒一次的
时钟更新都会 `requestLayout()` 并向上走到窗口根节点，连带重新测量歌词页那段
整首歌高度的 TextView。

修复：时间文本固定为 `40dp x 13dp`。真机 20 秒稳态从
`Slow UI thread 11/20、P95 44ms` 降到 `Slow UI thread 1/20、P95 34ms`。

### BUG-033：歌词逐行高亮触发整块重排

高亮同时使用 `StyleSpan(BOLD)` 与 `RelativeSizeSpan(1.45)`，两者都是
`MetricAffectingSpan`，每换一行都要重新测量整首歌词并重新 `setText`。

修复：整首歌词只在换歌时 `setText` 一次，之后仅在 TextView 已持有的
`Spannable` 上移动一个 `ForegroundColorSpan`。颜色 Span 不影响度量，
TextView 只 invalidate 受影响的行。

### BUG-034：资料库列表不复用行视图

`NetworkMusicActivity` 的 `getView()` 忽略 `convertView`，1242 首的
「我喜欢」每滚动一格都要新建 `LinearLayout` + 两个 `TextView`（专辑/歌手
分组还要多一个 `ImageView`）。

修复：改为 ViewHolder 复用；封面按 `?param=120y120` 请求服务端缩略图并以
`RGB_565` 解码。真机滚动从 `8.39% janky / P95 17ms` 降到
`3.92% janky / P95 13ms`。

### BUG-035：布局 margin 被 `layout_margin` 吞掉

新播放页同时写了 `android:layout_margin="0dp"` 和 `layout_marginStart/End`。
`MarginLayoutParams` 在 `layout_margin >= 0` 时直接忽略单边 margin，六个
按钮因此完全贴在一起。修复：删除 `layout_margin`，只保留单边 margin。

### BUG-036：菜单「我喜欢的音乐」被截断

`ItemMenuTitle` 为 19sp，配 45dp 图标和 10dp 起始内边距后超出 189dp 面板宽度。
修复：图标 34dp、标题 15sp，单屏可见项由 3 增至 4。

## 构建与发布加固

- 本地 `build_network_bridge.ps1` / `build_suixin_network.ps1` 之前硬编码了
  SDK 绝对路径和明文签名口令，与公开仓库里已脱敏的版本不同，按原样同步会把
  凭据写进 GitHub。两侧统一为读环境变量，机器相关配置放到 git 忽略的
  `scripts/local-build-env.ps1`，模板为 `local-build-env.example.ps1`；
  `sync_publish.py` 也显式排除该文件，避免它落到发布目录。
- 版本号只在 `patch_suixin.py` 维护，构建脚本从 `apktool.yml` 回读 `versionName`
  命名产物，不再每次发版手改脚本。
- 新增 `scripts/sync_publish.py` 固定公开仓库的文件子集，避免把反编译母版、
  逆向工作区和工具链带进仓库。

## UI 重构内容

- **播放页** `fragment_activity_main_play.xml` 全部重写：新增可读性渐变蒙版；
  标题/歌手居中并带阴影；音质独立成行，不再挤进 `@id/artist` 并被压到 8sp；
  新增已播/总时长；传输键由 50/58dp 缩到 36/52dp，底部键由 50dp 缩到 30dp，
  三键间距 12dp / 18dp；新增缓冲、解析、离线缓存与错误状态行。
- **歌词页** `fragment_activity_main_lyric.xml` 全部重写：滚动容器写进 XML，
  bridge 不再在每个 Activity 实例上把 `@id/tip` 拆出来重新挂载；新增暗色蒙版；
  正文 13sp、行距 8dp、`breakStrategy=simple`。
- **音量面板** `dialog_volume.xml`：滑条由 50dp 压到 26dp，补充「系统媒体音量」
  与「表冠与音量键同步调节」说明；`activity_main.xml` 的音量浮层由全屏条改为
  贴近表冠的 22dp 竖条。
- **菜单** `ItemMenuImage` 45dp→34dp、`ItemMenuTitle` 19sp→15sp，
  「我喜欢的音乐」不再被截断，单屏可见项由 3 增至 4。
- **资料库** 标题 25sp→17sp、行标题 18sp→13sp、副标题 14sp→9.5sp，
  单屏可见曲目由 3 增至 5。
- **封面背板** 写入 `activity_main.xml`，bridge 只设置 Bitmap，不再
  `addView` 到 `@id/main`；母版模糊/流体背景仍同步收到同一张封面。

所有资源改动放在 `res-overlay/`，由 `scripts/patch_suixin.py` 的
`patch_watch_ui()` 幂等地覆盖到 apktool 树，保证从干净反编译可复现。
新增 id 不写入 `public.xml`，aapt2 另行分配，母版既有 id 保持不变；
`binding_1..binding_5` 标签、根 tag 和全部既有 id/控件类型均未改动，
DataBinding 映射不受影响。

## 未完成 / 环境受限

- 歌词页单独的 `gfxinfo` 场景未采到：测试期间手表正在运行「自由记录」运动会话，
  系统层抢占横向手势，注入的 ViewPager 翻页多次被切到系统应用。歌词页功能与
  三秒回中已用截图确认，性能以歌词页始终挂载状态下的稳态数据代替。
- 表冠旋转无法用 `adb input` 注入 `AXIS_SCROLL`，表冠调音与表冠滚动歌词沿用
  母版链路，需佩戴实测。
- 网络 ADB 无法真正写入手表：production user 固件拒绝 `persist.adb.tcp.port`，
  `settings put global adb_wifi_enabled 1` 被框架回滚为 0。常驻改由 PC 侧
  `scripts/watch_adb_keepalive.ps1` 保活，详见 `docs/DEVELOPMENT_GUIDE.md`。
