# 1.5.1 - 设置页去品牌、全局过渡动画与图标刷新

日期：2026-07-26
版本：`1.5.1 / 10501`
上一稳定版：`1.5.0 / 10500`（保留）

## 需求范围

| 项 | 内容 |
| --- | --- |
| 品牌去标识化 | 清除设置/关于页原作者残留 |
| 过渡动画 | 全局页面切换动画，低功耗、低性能设备流畅 |
| 图标刷新 | 设置/菜单圆底图标重绘 |

## 实现

### 去品牌

- 关于页删除硬编码的原作者备案号 `粤ICP备2023066011号-5A`；
  `Developed by …` 改为 `随心一听 · 开源社区`。
- 全树复核：用户协议、隐私政策 assets 已是「随心一听开源社区」，无
  sky233 / 晞云 / 零度 / lightxi 残留。`sky130` 仅为 widget 内部包名（不可见），
  改名需重命名全部类、风险极高，不改。
- APK 二进制不再含字符串 `2023066011`。

### 全局过渡动画

- 新增窗口动画并挂到 App 主题 `Base.Theme.ZeroMusic` 的
  `windowAnimationStyle`：
  - 活动页开/关：滑动 + 淡入淡出（`activityOpen/Close*Animation`，~210ms）。
  - 弹窗：纯淡入淡出 + 轻微上移（`windowEnter/ExitAnimation`，~150ms）。
- 全部为窗口层 translate/alpha，RenderThread 合成，不上 UI 线程测量/布局，
  结束即停、无循环、无 fillAfter，低功耗。
- 资源在 `res-overlay/anim/`，由 `patch_settings_ui()` 幂等挂载。

### 图标刷新

- 母版 17 个圆底图标（扫描、界面、主题、文件传输、歌词、播放、帮助、关于、
  定时、专辑、歌手、设置、均衡器、音乐库、播放队列、播放列表、完整功能）由
  纯色 `#6186fc` 圆底改为自上而下对角线性渐变 `#7FA0FF → #4762EC`，
  白色字形保持不变。
- 渐变端点按各图标 viewport（160/165/70）等比缩放；`ic_default_menu_*` 为
  无圆底纯蓝字形，按 `pathData` 是否 `M0,` 起始精确排除，保持原样。
- 矢量渐变仍是单个编译 drawable，运行时零额外绘制；由 `patch_icons()` 幂等生成。
- 离线预览：`artifacts/icons_preview.png`（Chrome headless 渲染矢量）。
